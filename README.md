# 🎬 Film Hub

**Film Hub** is a modern and fully responsive **Movie Website** built with **JavaScript** and a free **Movie API**.  
You can search for **any film**, view its **full details**, and explore extra pages like **About**, **Contact**, and **Download**.

---

## 🚀 Features

- 🔎 **Search movies** by title  
- 🎥 View **all film details** (title, year, rating, cast, plot, poster, etc.)  
- 📱 Fully **responsive design** (works on desktop & mobile)  
- 📄 Extra pages:  
  - 📝 **About** page  
  - 📬 **Contact** page  
  - ⬇️ **Download** page  

---

## 🛠️ Tech Stack

- **HTML5**  
- **CSS3** (Responsive UI + modern design)  
- **JavaScript (ES6)**  
- **Movie API** ([OMDb API](https://www.omdbapi.com/) or your chosen API)
